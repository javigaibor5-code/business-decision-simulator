# 📊 Business Decision Simulator

An interactive web tool that helps small business owners understand their
numbers in real time: break-even point, contribution margin, profit margin,
and a 6-month profit projection based on expected growth.

Unlike a typical portfolio project, this tool is built to be genuinely useful:
anyone can enter their own price, costs, and expected sales, and immediately
see whether their business model is financially viable.

## 💡 Why I built this
As a Business Management Engineer now studying Software Development, I wanted
a project that shows both sides of my profile: understanding real business
metrics (break-even analysis, contribution margin) **and** the ability to turn
that knowledge into an interactive, usable tool.

## ✨ Features
- Real-time calculation as you type — no submit button needed
- **Break-even analysis chart**: visualizes where Total Revenue crosses Total Cost
- **6-month profit projection chart**: models growth based on an expected monthly growth rate
- Instant feedback banner: tells you clearly whether your numbers are profitable or not
- Fully responsive layout

## 🛠️ Technologies
- HTML5, CSS3 (Grid, responsive design)
- JavaScript (real-time calculations, DOM updates)
- Custom SVG data visualization (no external charting library — fully self-contained)

## 📚 Business concepts applied
- Contribution margin (price − variable cost)
- Break-even point (fixed costs ÷ contribution margin)
- Profit margin
- Growth projection modeling

## 🚀 How to run it locally
1. Clone this repository
2. Open `index.html` in your browser (fully self-contained, no external dependencies or internet connection required)
